# 🚀 FluxOS

**Gestão de Ordens de Serviço de forma simples, organizada e eficiente.**

O **FluxOS** é um sistema SaaS desenvolvido para empresas que trabalham com prestação de serviços e precisam centralizar o controle de **clientes, ordens de serviço, equipes, serviços e atendimentos** em um único lugar.

A proposta é transformar processos que normalmente são feitos por WhatsApp, planilhas e anotações em um fluxo organizado, rápido e fácil de acompanhar.

---

## 📌 Sobre o projeto

O FluxOS está sendo desenvolvido com foco em pequenas e médias empresas que precisam de uma solução prática para gerenciar suas operações sem a complexidade de sistemas empresariais tradicionais.

### Principais objetivos

- 📋 Criar e gerenciar ordens de serviço
- 👥 Gerenciar clientes
- 👨‍🔧 Controlar técnicos e equipes
- 📅 Organizar atendimentos
- 📊 Acompanhar o andamento dos serviços
- 📎 Centralizar informações e documentos
- 🔔 Facilitar o acompanhamento de prazos e pendências
- 📱 Oferecer uma interface simples e responsiva

## ⚙️ Instalação

### 1. Clone o repositório

```bash
git clone https://github.com/Gabii1901/FluxOS.git
```

### 2. Entre na pasta

```bash
cd FluxOS
```

### 3. Configure o Backend

Entre na pasta:

```bash
cd backend
```

Inicie o backend

```bash
npm run dev
```

### 4. Configure o Frontend

```bash
cd ../frontend
```
Inicie o frontend

```bash
npm run dev
```

As instruções específicas do frontend serão adicionadas conforme a estrutura do projeto for definida.

## 💡 Proposta

O FluxOS nasceu com uma ideia simples:

> **Menos planilhas. Menos papel. Menos mensagens perdidas. Mais controle.**

A intenção é criar uma ferramenta que realmente facilite o dia a dia de empresas que trabalham com serviços, sem exigir uma curva de aprendizado complicada.
